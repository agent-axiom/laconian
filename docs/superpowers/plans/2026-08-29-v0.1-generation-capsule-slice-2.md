# Laconian v0.1 Generation Capsule Slice 2 Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add conservative provider-delivery evidence, deterministic OpenAI transport, exact sanitization, and strict canonical `RawAttemptV2` rows without changing the legacy v1 schema/serializer or bytes for identical pre-existing provider outcomes.

**Architecture:** Extend the provider boundary with immutable normalized success/error evidence while leaving `runner.run_to_jsonl` as the unchanged v1 compatibility consumer. Build the v2 evidence layer separately in `laconian_eval.capsule.attempts`: sanitize provider-controlled bytes first, validate one normalized truth-table state, derive identities from canonical persisted bytes, and migrate replay data only when the strict v2 row model lands.

**Tech Stack:** Python 3.11+, Pydantic 2, OpenAI Python SDK 3.x with `DefaultHttpxClient`, PyYAML 6, pytest, Ruff, mypy, canonical JSON/SHA-256 helpers from Slice 1.

The result API is exact:

```python
@dataclass(frozen=True, slots=True)
class SanitizedOutput:
    text: str | None
    byte_length: int
    sha256: str
    credential_replacement_count: int

    @property
    def was_redacted(self) -> bool:
        return self.credential_replacement_count > 0
```

`sanitize_output(value: str, *, patterns: SanitizerPatterns)` requires an exact built-in, nonblank, strict-UTF-8 string; applies only credential patterns; streams the transformed chunks through SHA-256 with bounded carry sufficient for the longest pattern and a complete UTF-8 code point; retains at most `output_utf8_bytes`; and clears retained chunks once the transformed size exceeds the limit. `byte_length` and `sha256` always describe the post-redaction bytes. It never constructs or hashes a pre-redaction whole-output byte copy.
