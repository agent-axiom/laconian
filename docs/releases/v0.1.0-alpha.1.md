# Laconian v0.1.0-alpha.1

Release date: 2026-08-30

Laconian is an experimental alpha for asking an agent for the shortest complete answer. This
release provides two pinned installation surfaces backed by the same canonical Markdown source:

- an installable one-file skill at `skills/if/SKILL.md`;
- a repo plugin installed from the `agent-axiom/laconian` marketplace at tag
  `v0.1.0-alpha.1`.

The accompanying evaluator supports Python 3.11 and 3.14. It is development infrastructure for
the open benchmark and is not being published to PyPI as part of this release.

## Release artifacts

The GitHub prerelease contains `laconian-plugin-v0.1.0-alpha.1.zip` and the matching
`laconian-plugin-v0.1.0-alpha.1.zip.sha256` SHA-256 checksum. The archive is assembled from an
explicit allowlist and contains the canonical skill, plugin metadata, README, changelog, and
license notices.

## Experimental boundary

This is an experimental alpha, not a final benchmark release. Interfaces and evaluation cases may
change before a stable release. No public benchmark result is included, and this release makes no
claim of measured token savings, superior answer quality, or acceptance into a universal plugin
directory.
